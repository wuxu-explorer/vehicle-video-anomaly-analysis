# 车辆视频异常数据分析系统

一个基于 Python 的车辆视频异常数据分析与巡检辅助系统，主要用于对车辆视频巡检过程中产生的 Excel 数据进行自动读取、统计分析、异常分析、月度数据对比以及分析报告生成。

项目主要面向车辆视频巡检、车辆异常状态统计、历史数据对比以及 Excel 数据自动化分析等场景。

当前主要版本为 **V9.0.0**。

---

## 一、项目简介

在车辆视频巡检过程中，通常会产生大量 Excel 数据。

传统人工分析方式需要反复进行：

* Excel 数据筛选
* 异常数据统计
* 车辆数量统计
* 行驶里程统计
* 报警数量统计
* 报警类型分析
* 车组异常分析
* 历史月份数据对比
* 报告整理

当数据量较大时，人工处理不仅效率较低，也容易出现统计遗漏和计算错误。

本项目通过 Python 对 Excel 数据进行自动化处理，将原本需要人工完成的数据读取、统计、分析、对比和报告生成过程进行自动化。

系统可以自动识别输入 Excel 文件中的统计月份，并根据数据完成车辆运营情况、报警情况以及重点风险车组等分析。

最终自动生成 Excel 和 Word 分析报告，并生成配套图表。

---

## 二、V9.0 核心功能

### 1. Excel 数据自动识别

程序可以自动扫描指定的数据目录，并识别其中符合要求的 Excel 文件。

程序不要求用户手动修改 Python 代码中的文件名称。

输入文件主要放置在：

```text
v8_pro/data/
```

程序运行时会自动扫描数据目录并识别可分析的 Excel 文件。

---

### 2. 月份自动识别

系统可以根据 Excel 中的统计日期等信息自动识别数据所属月份。

例如：

```text
旧月份：6月
新月份：7月
```

程序会自动确定两份数据的先后关系，并将其用于后续月份对比分析。

---

### 3. 车辆运营数据分析

系统可以对不同月份的车辆运营情况进行统计。

主要包括：

* 运行车辆数量
* 总运行里程
* 报警总数量

例如一次实际运行结果：

```text
6月：707辆，1,299,513.25 KM，130632次报警
7月：644辆，1,706,188.87 KM，150919次报警
```

系统可以进一步对新旧月份数据进行比较。

---

### 4. 月度数据对比

系统会自动对两个月份的数据进行对比分析。

主要分析：

* 车辆数量变化
* 总运行里程变化
* 报警数量变化
* 报警相关指标变化

通过自动计算，减少人工进行 Excel 对比的工作量。

---

### 5. 报警类型分析

系统可以对 Excel 中的报警数据进行分类统计。

根据输入数据中的报警类型，对不同报警进行数量统计和分析。

通过报警类型统计，可以快速了解当前月份主要风险来源。

---

### 6. 重点风险车组分析

系统会根据报警数据对车辆所属车组进行统计分析。

主要用于发现：

* 报警数量较高的车组
* 异常较集中的车组
* 需要重点关注的车辆群体

通过车组维度进行分析，可以辅助后续巡检和风险排查。

---

### 7. 自动生成图表

程序运行过程中会自动生成分析所需的图表。

图表统一保存到：

```text
v8_pro/output/charts/
```

图表用于辅助展示：

* 车辆运营数据
* 报警数据
* 月份变化
* 风险分析结果

---

### 8. 自动生成 Excel 报告

程序运行结束后，会自动生成结构化 Excel 分析报告。

默认输出目录：

```text
v8_pro/output/
```

主要结果文件：

```text
车辆运营与报警月度分析报告.xlsx
```

Excel 报告用于进一步查看详细分析数据。

---

### 9. 自动生成 Word 报告

系统同时支持自动生成 Word 分析报告。

主要结果文件：

```text
车辆运营与报警月度分析报告.docx
```

Word 报告主要用于：

* 月度汇报
* 工作总结
* 数据分析展示
* 巡检结果整理

```text
      ▼

      │
      ▼

      │
      ▼
车辆运营数据分析
      │
      ├──────────────┐
      ▼              ▼
报警数据分析      重点风险车组分析
      │              │
      └───────┬──────┘
              ▼
        新旧月份数据对比
              │
              ▼
          生成分析图表
              │
        ┌─────┴─────┐
        ▼           ▼

```

## 十二、数据安全说明

项目不建议将真实业务 Excel 数据直接上传到 GitHub。

真实数据可能包含：

* 车辆信息
* 设备信息
* 车组信息
* 报警记录
* 企业内部业务数据

因此项目通过 `.gitignore` 对本地数据和程序运行结果进行忽略。

建议：

```text
v8_pro/data/
```

仅用于本地存放真实分析数据。

同时：

```text
v8_pro/output/
```

用于存放本地生成的分析结果。

真实业务数据不应作为项目源码提交到公开 GitHub 仓库。

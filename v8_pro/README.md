# 车辆视频异常巡检与运营报警分析系统

## 项目简介

本项目是一个基于 Python 和 Excel 的车辆运营、报警及视频异常数据自动分析工具。

系统能够自动读取车辆相关 Excel 报表，根据 Excel 内部数据识别分析周期，并完成数据统计、趋势分析、异常识别及报告生成。

目前支持单份 Excel 独立分析，也支持两份 Excel 自动识别新旧数据并进行对比。

## 主要功能

### 1. Excel 数据自动识别

系统能够自动读取 Excel 工作簿及工作表，并根据字段和数据内容识别：

* 车辆里程数据
* 报警明细数据
* 视频异常数据
* Excel 内部日期及分析周期
* 车辆、车组及单位等相关字段

程序不要求用户按照固定名称修改 Excel 文件名。

### 2. 单份 Excel 独立分析

当 `data/` 文件夹中只有一份 Excel 时，程序可以进行单文件分析并自动生成报告。

主要统计：

* 运行车辆数
* 总运行里程
* 总报警次数
* 百公里风险事件数
* 九类重点报警
* 各单位报警数据
* 高频违规车组
* 视频异常
* 数据质量

### 3. 两份 Excel 自动对比

当 `data/` 文件夹中存在两份 Excel 时，程序会优先根据 Excel 内部日期识别数据周期，并自动确定旧数据与新数据。

自动比较：

* 运行车辆数变化
* 总运行里程变化
* 总报警次数变化
* 百公里风险事件变化
* 九类报警次数变化
* 九类报警占比变化
* 各单位报警变化

趋势判断支持：

* 上升
* 下降
* 基本持平
* 无法比较

### 4. 九类重点报警分析

系统目前支持以下九类重点报警：

1. 车距过近
2. 疲劳驾驶
3. 驾驶员分心
4. 无驾驶员
5. 违规打电话
6. 违规抽烟
7. 碰撞报警
8. 左右盲区报警
9. 驾驶员打哈欠

系统会自动统计各报警类型的：

* 报警次数
* 占总报警比例
* 新旧数据变化
* 报警趋势

同时支持按照单位进行报警数据统计。

### 5. 典型违规案例分析

系统能够自动生成高频违规车组 TOP 榜，包括：

* 车距过近高频违规车组 TOP5
* 疲劳驾驶高频违规车组 TOP10
* 打电话和抽烟违规车组 TOP5
* 前车碰撞高频违规车组 TOP5
* 左右盲区违规车组 TOP5
* 驾驶员分心驾驶高频违规车组 TOP10

### 6. 视频异常分析

系统会对视频异常进行自动识别，并按照固定业务优先级进行分类：

**DMS > ADAS > DSC > 普通摄像头 > 未知**

其中：

* DMS：驾驶员监控相关系统
* ADAS：高级驾驶辅助相关系统
* DSC：驾驶员状态相关系统
* 普通摄像头：普通视频监控设备

业务优先级固定为：

> DMS > ADAS > DSC > 普通摄像头

即使普通摄像头异常数量更多，也不会覆盖 DMS、ADAS、DSC 等重点系统。

系统还能够统计重点系统的异常次数以及高频异常车组。

### 7. 数据质量自动检查

程序在生成报告之前会自动检查数据质量，包括：

* Excel 内部日期是否识别
* 运行车辆数是否正常
* 总运行里程是否正常
* 报警明细工作表是否识别
* 总报警次数是否正常
* 九类报警分类是否完整
* 报警车组字段是否缺失
* 九类报警合计是否一致
* 视频异常工作表是否识别
* 视频系统是否完成分类

程序不会为了生成报告而擅自补充或修改原始数据。

如果发现严重问题或警告，会在报告中明确显示。

### 8. 自动生成 Excel 报告

程序能够自动生成 Excel 分析报告，主要包括：

1. 车辆运营里程
2. 报警趋势分析
3. 典型违规案例
4. 重点视频异常
5. 数据质量检查

同时包含：

* 数据表格
* 自动格式化
* 百分比格式
* Excel 图表
* 冻结表头
* 自动筛选
* 数据质量检查结果

### 9. 自动生成 Word 报告

程序能够同时生成适合汇报使用的 Word 分析报告。

报告主要包括：

1. 本期运营情况摘要
2. 车辆运营里程
3. 报警趋势分析
4. 典型违规案例晾晒
5. 重点视频异常
6. 数据质量检查

Word 报告同时包含自动生成的分析图表和核心指标摘要。

建议使用：

* Python 3.13
* pandas
* numpy
* openpyxl
* python-docx
* matplotlib

## 安装依赖

在项目根目录打开终端，执行：

```bash
py -m pip install pandas numpy openpyxl python-docx matplotlib
```

也可以分别检查依赖是否安装：


## 使用方法

### 第一步：准备 Excel

将需要分析的 Excel 文件放入：

```text
data/
```

支持：

* 一份 Excel → 单文件分析
* 两份 Excel → 新旧数据自动对比

不要求修改 Excel 文件名。

### 第二步：运行程序

在项目根目录终端执行：

```bash
py main.py
```

### 第三步：查看结果

程序运行完成后，分析结果会生成到：

```text
output/
```

主要包括：

```text
车辆运营与报警月度报告_V8_7.xlsx
车辆运营与报警月度报告_V8_7.docx
```

具体文件名称以 `config.py` 中的配置为准。

## 测试数据

## 数据安全

请勿将真实业务数据、车辆信息、个人信息、账号密码、Cookie、API Key 或其他敏感信息上传到公开 GitHub 仓库。

实际业务 Excel 建议仅保存在本地 `data/` 文件夹中。

项目中的测试数据仅用于功能测试。

## 注意事项

1. Excel 原始数据格式不同可能导致部分字段无法自动识别。
2. 如果报告出现数据质量警告，应优先检查原始 Excel。
3. 程序不会为了生成报告而自动补齐缺失数据。
4. DMS、ADAS、DSC 的识别依赖 `config.py` 和 `main.py` 中的规则。
5. 单位识别规则也可以通过 `config.py` 进行调整。

## 项目定位

本项目目前定位为：

**车辆运营、报警及视频异常数据自动分析与报告生成工具。**

目标是减少人工整理 Excel、统计报警数据及制作分析报告的工作量，提高数据分析和报告生成效率。

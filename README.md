# 车辆视频异常数据分析系统

一个基于 Python 的车辆视频异常数据分析与运营报告生成系统，主要用于对车辆视频巡检、车辆运营及报警 Excel 数据进行自动化分析、统计、对比和报告生成。

项目通过 Python 对 Excel 数据进行自动读取、字段识别、数据统计、异常分析和结果输出，减少人工筛选、统计和计算工作，提高数据分析效率。

当前项目以 **V9.0** 为主要版本，V7、V8 Lite、V8 Pro 等版本作为项目迭代过程保留。

---

## 一、项目简介

在车辆视频巡检和运营数据分析过程中，通常需要人工处理大量 Excel 数据，包括：

* 数据筛选
* 异常分类
* 报警统计
* 车组统计
* 新旧月份数据对比
* 风险车组识别
* 分析结果整理
* Excel / Word 报告制作

本项目通过 Python 将上述过程进行自动化处理。

系统可以读取 Excel 数据，并根据数据内容完成分析，最终自动生成结构化分析结果和运营报告。

## 三、V9.0 核心功能

### 1. Excel 数据自动识别

程序可以扫描指定的数据目录，并根据 Excel 文件内容识别不同类型的数据。

支持根据 Excel 中的字段和数据特征判断报告类型，减少对固定文件名的依赖。

---

### 2. 车辆运营数据分析

系统可以对车辆运营统计数据进行分析，包括：

* 运行车辆数量
* 总运行里程
* 月度数据统计
* 新旧月份数据对比
* 运行数据变化分析

例如：

```text
6月：
运行车辆：707辆
运行里程：1,299,513.25 KM
报警次数：130632次

7月：
运行车辆：644辆
运行里程：1,706,188.87 KM
报警次数：150919次
```

程序可以自动计算不同月份之间的数据变化。

---

### 3. 报警数据分析

系统可以对报警数据进行统计和分类分析，包括：

* 报警总量
* 报警类型统计
* 报警趋势
* 报警占比
* 单位报警统计
* 重点报警类型分析

---

### 4. 车组异常分析

系统可以按照车辆所属车组进行统计，帮助快速定位异常较多的车辆组。

同时可以进一步结合通道信息，对：

```text
车组
 +
通道
 +
异常状态
```

进行统计分析。

---

### 5. 新旧月份自动对比

V8 Pro / V9.0 支持对两份不同时间的数据进行自动对比。

主要分析：

```text
旧数据
   ↓
新数据
   ↓
数据匹配
   ↓
变化识别
   ↓
新增异常
   ↓
异常消失
```

可以识别：

* 新增异常
* 消失异常
* 异常数量变化
* 车组异常变化
* 通道异常变化

---

### 6. 重点风险车组分析

系统可以根据报警及异常数据，对重点风险车组进行统计。

用于帮助使用者快速发现：

* 异常数量较高的车组
* 报警较多的车组
* 重点异常类型集中的车组

---

### 7. 自动生成图表

系统可以根据分析结果自动生成图表，并保存到输出目录。

例如：

```text
output/
└── charts/
```

图表可以用于辅助查看：

* 月度数据变化
* 报警数据变化
* 报警类型统计
* 重点车组分析

---

### 8. Excel 报告生成

程序运行结束后，可以自动生成结构化 Excel 分析结果。

Excel 报告用于进一步的数据查看、筛选和汇报。

---

### 9. Word 报告生成

V9.0 同时支持生成 Word 分析报告。

Word 报告可以用于：

* 月度运营总结
* 异常分析
* 报警情况汇报
* 数据分析结果展示

## 十二、数据安全

项目涉及车辆运营和视频巡检数据，因此：

**真实业务 Excel 数据不建议直接上传到公开 GitHub。**

项目通过 `.gitignore` 忽略本地运行数据和输出结果。

例如：

```text
data/
output/
charts/
```

真实业务数据应保存在本地环境中。

GitHub 仓库主要保存：

* Python 源代码
* 配置文件
* README
* requirements.txt
* 测试代码
* 示例说明
* 项目截图

这样可以避免将真实业务数据公开到互联网。

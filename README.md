# 🚗 车辆视频异常数据分析系统

一个基于 Python 的车辆视频异常数据分析工具，主要用于对车辆视频巡检及异常报警数据进行自动化整理、统计、分析和报告生成。

项目面向车辆运营及视频监控数据分析场景，可以从 Excel 数据中识别和统计车辆异常情况，并对不同时间段的数据进行对比分析，提高人工巡检和数据统计效率。

---

## 📌 项目简介

在车辆视频巡检过程中，通常需要人工查看 Excel 数据，并统计不同车辆、单位以及异常类型的数据。

当数据量较大时，人工统计容易出现：

- 数据量大，统计耗时
- 人工计算容易出错
- 不同时间的数据难以快速比较
- 异常车辆筛选效率较低
- 报告整理工作重复性较高

因此，本项目通过 Python 对 Excel 数据进行自动化处理，实现车辆视频异常数据的快速分析。

---

## ✨ 主要功能

### 1. Excel 数据分析

支持读取车辆视频异常相关 Excel 数据，并自动进行数据整理和统计。

主要分析内容包括：

- 车辆运行数据
- 行驶里程
- 报警数量
- 异常事件
- 单位报警数据
- 车辆组异常数据

---

### 2. 报警数据统计

对常见车辆视频报警类型进行统计分析，包括：

- 车距过近
- 疲劳驾驶
- 驾驶员分心
- 无驾驶员
- 违规打电话
- 违规抽烟
- 碰撞报警
- 左右盲区报警
- 驾驶员打哈欠

系统可以统计不同报警类型的数量及占比。

---

### 3. 数据趋势对比

支持对不同时间的数据进行对比。

可以分析：

- 总运行车辆数量变化
- 总运行里程变化
- 总报警数量变化
- 百公里风险事件变化
- 各类报警占比变化
- 各单位报警数据变化

并根据数据变化判断相关指标呈现：

- 上升
- 下降
- 基本稳定

---

### 4. 异常车辆及车辆组分析

系统可以对车辆异常数据进行排序和筛选。

例如：

> 自动找出“车距过近”报警次数最高的车辆组。

同时可以进一步分析不同单位、车辆组的异常情况。

---

### 5. 自动生成分析结果

通过程序自动完成数据统计和分析，减少人工计算工作。

最终可以形成结构化的分析结果，为车辆视频巡检和运营管理提供数据支持。

---

## 🧠 系统分析重点

本项目重点关注车辆智能视频相关系统。

其中包括：

### DMS

Driver Monitoring System

驾驶员监控系统。

主要关注驾驶员状态，例如：

- 疲劳驾驶
- 驾驶员分心
- 打电话
- 抽烟
- 打哈欠
- 无驾驶员等

---

### ADAS

Advanced Driver Assistance Systems

高级驾驶辅助系统。

主要关注车辆行驶过程中的道路及驾驶风险，例如：

- 车距过近
- 碰撞风险
- 盲区风险等

---

### DSC

根据具体车辆及设备配置，用于车辆视频监控相关的数据分析。

项目可以根据不同数据源和通道信息，对相关异常进行分类分析。

# 🚗 车辆视频异常数据分析系统

一个基于 Python 的车辆视频异常数据分析工具，主要用于对车辆视频巡检产生的 Excel 数据进行自动化统计、异常分析和数据对比。

项目针对车辆视频巡检过程中数据量较大、人工统计耗时以及多期数据对比不方便等问题进行开发，能够从 Excel 数据中提取车辆运行、报警及异常信息，并生成结构化的分析结果。

---

## 📌 项目简介

在车辆视频巡检工作中，需要定期对车辆视频及智能驾驶相关异常数据进行统计分析。

传统人工处理通常需要：

1. 打开 Excel 数据文件
2. 筛选车辆及单位数据
3. 统计报警数量
4. 计算不同报警类型占比
5. 对比不同时间的数据
6. 查找重点异常车辆组
7. 整理最终分析结果

当数据量较大时，人工处理容易出现效率低、重复工作多以及计算错误等问题。

因此，本项目使用 Python 对相关 Excel 数据进行自动化处理，将数据读取、统计、分析和对比等工作程序化。

---

## ✨ 主要功能

### 1. Excel 数据读取与分析

程序能够读取车辆视频异常相关 Excel 数据，并对数据进行统计分析。

主要涉及：

- 车辆运行数据
- 行驶里程数据
- 报警数据
- 异常事件数据
- 单位数据
- 车辆组数据

---

### 2. 车辆运行数据分析

对车辆运行情况进行统计，包括：

- 运行车辆数量
- 总运行里程
- 不同时间数据对比
- 运行里程增加/减少情况

通过对不同时间的 Excel 数据进行比较，可以快速了解车辆运行数据的变化情况。

---

### 3. 报警数据统计

程序对车辆视频相关报警数据进行分类统计。

目前重点分析的报警类型包括：

- 车距过近
- 疲劳驾驶
- 驾驶员分心
- 无驾驶员
- 违规打电话
- 违规抽烟
- 碰撞报警
- 左右盲区报警
- 驾驶员打哈欠

可以统计各类报警的：

- 报警数量
- 占全部报警的比例
- 与上一期数据的变化情况
- 上升或下降趋势

---

### 4. 多期数据对比

项目支持对不同时间的 Excel 数据进行对比分析。

主要比较：

- 总运行车辆数量
- 总运行里程
- 总报警数量
- 百公里风险事件
- 各类报警数量
- 各类报警占比

通过对比新旧数据，可以快速判断相关指标是：

- 上升
- 下降
- 发生变化

---

### 5. 各单位报警数据分析

程序能够根据数据中的单位信息，对不同单位的报警情况进行统计。

可以用于了解：

- 各单位报警数量
- 不同单位之间的报警差异
- 重点异常单位

帮助快速定位需要重点关注的数据对象。

---

### 6. 重点异常车辆组分析

针对典型异常情况进行排序分析。

目前重点支持：

> “车距过近”报警次数 TOP 5 车辆组

程序可以根据报警次数自动进行排序，快速找出异常频率较高的车辆组。

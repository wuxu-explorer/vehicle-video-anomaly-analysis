# 车辆视频异常数据分析系统

一个基于 Python 的车辆视频异常数据分析与巡检系统，主要用于对车辆视频巡检过程中产生的 Excel 数据进行自动化统计、异常分析以及多份报表之间的数据对比。

项目目前以 V8 Pro 双报表分析版本为主要版本，支持两份 Excel 报表的独立分析与自动对比，并生成结构化 Excel 分析结果。

---

## 一、项目简介

车辆视频异常数据分析系统主要面向车辆视频巡检、车辆异常状态统计以及历史数据对比等场景。

传统人工分析 Excel 数据时，需要反复进行数据筛选、分类、统计和对比，效率较低，同时容易出现统计遗漏和人工计算错误。

本项目通过 Python 对 Excel 数据进行自动读取、字段识别、异常统计和结果输出，将原本需要人工完成的数据处理流程进行自动化。

项目目前已经完成 V7、V8 Lite 和 V8 Pro 等多个版本，其中 V8 Pro 重点实现了：

- 双 Excel 报表独立分析
- 两份报表自动识别
- 异常数据统计
- 车组-通道异常统计
- 新旧报表自动对比
- 新增异常识别
- 异常消失识别
- Excel 分析结果自动生成

---

## 二、项目主要功能

### 1. Excel 数据自动读取

程序可以自动读取指定目录中的 Excel 数据文件，并对输入数据进行分析。

V8 Pro 支持两份 Excel 报表进行分析。

默认数据目录：

```text
v8_pro/data/
```

推荐文件名称：

```text
data_A.xlsx
data_B.xlsx
```

---

### 2. 双报表独立分析

V8 Pro 会分别读取 A、B 两份 Excel 报表，并独立统计其中的异常数据。

程序运行过程中会输出类似：

```text
A：异常明细 64，车组-通道 43
B：异常明细 7113，车组-通道 551
```

这样可以分别了解两个时间节点或两个数据报表中的异常情况。

---

### 3. 异常明细统计

程序可以对输入 Excel 中的异常数据进行整理和统计，并生成结构化的异常明细结果。

---

### 4. 车组-通道异常统计

系统会对车辆所属车组以及异常通道进行统计，帮助快速了解不同车组、不同通道的异常情况。

---

### 5. 新旧数据自动对比

V8 Pro 可以对 A、B 两份报表进行自动对比，并识别异常变化。

主要包括：

- 新增异常
- 异常消失

程序会输出变化统计，例如：

```text
===== 对比变化统计 =====
变化状态
新增异常    551
异常消失     43
```

---

### 6. 自动生成分析结果

程序运行结束后，会自动生成 Excel 分析结果。

输出目录：

```text
v8_pro/output/
```

默认结果文件：

```text
视频异常巡检V8_双报表分析与对比.xlsx
```

## 三、项目处理流程

```text
Excel 原始数据
      │
      ▼
读取 A / B 两份报表
      │
      ▼
字段识别与数据校验
      │
      ▼
异常数据整理
      │
      ├───────────────┐
      ▼               ▼
A 报表独立分析      B 报表独立分析
      │               │
      └───────┬───────┘
              ▼
        新旧数据自动对比
              │
              ▼
      新增异常 / 异常消失
              │
              ▼
        生成 Excel 分析结果
```

## 四、V8 Pro 双报表分析

```text

      │
      ├── 异常明细统计

      ▼

  │
  ▼

  │
  ├── 新增异常
  └── 异常消失
```

## 十二、数据字段校验

为了避免输入错误的数据导致分析结果异常，V8 Pro 在读取 Excel 后会进行字段校验。

程序会检查输入报表是否包含分析所需的字段。

如果字段不完整，程序会给出明确的错误提示，并列出缺少的字段以及当前 Excel 中实际存在的字段。

例如：

```text
输入报表字段不完整
```

这样可以帮助使用者快速定位输入数据格式问题。

---

## 十三、异常处理

程序对常见输入问题进行了基础处理，包括：

- Excel 文件数量不足
- Excel 字段不完整
- 输入数据格式异常
- 数据读取失败
- 输出结果生成失败

当程序出现异常时，会输出错误类型和具体错误信息，方便定位问题。

## 十四、数据安全

项目中的真实车辆数据不建议直接上传 GitHub。

项目通过 `.gitignore` 忽略本地数据和运行结果，例如：

```text
**/data/*.xlsx
**/data/*.xls
**/output/*
```

因此：

```text
v8_pro/data/
```

中的真实 Excel 数据不会作为项目源码提交。

同时：

```text
v8_pro/output/
```

中的本地运行结果也不会被提交。

GitHub 仓库主要保存：

- Python 源代码
- 配置文件
- README
- 项目结构
- requirements.txt
- 示例截图
- 测试代码
